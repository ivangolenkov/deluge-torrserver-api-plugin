# Отчёты о реализации

Здесь фиксируется фактический результат фаз и значимых частей работы. Основной шаблон — [report-template.md](report-template.md).

Ожидаемые имена: phase0-report.md, phase1-report.md, …, phase5-report.md. Эти файлы создаются при начале реальной работы над соответствующей фазой, а не заранее с фиктивным статусом готовности.

Для завершённой фазы обязательны:

- Изменённое поведение и перечень файлов.
- Полный DoD исходной фазы с отметками и ссылками на подтверждение.
- Точные проверки, команды, версии, архитектура и результат.
- Статус относящихся к фазе сценариев A01–A26, включая непроверенные части.
- Обновления README, Makefile и GitHub Actions.
- Отклонения, оставшиеся ограничения и готовность к следующему этапу.

Невыполненные проверки указываются прямо. Отсутствие окружения, сервиса или доступа к GitHub не означает успешный тест. Черновик workflow не считается успешным CI, а dry-run не считается опубликованным релизом.
